# Mudassir Javed Portfolio

React, TypeScript, Vite, Tailwind CSS, Framer Motion, and Lucide React foundation for the Mudassir Javed portfolio.

## Commands

- `pnpm dev` — start the local development server
- `pnpm typecheck` — run TypeScript project checks
- `pnpm build` — create a production build
- `pnpm preview` — preview the production build locally

Portfolio requirements and verified content are maintained in `docs/`.
